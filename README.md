# alphaBell

Research models, failure traces and tools for testing model behavior.

| Project | What you can do |
| --- | --- |
| [Model Observatory](https://huggingface.co/spaces/alphabell/Model-Observatory) | Replay measured Flint and Qwen captures and inspect source-pinned model layouts. |
| [Kernel Trap Cards](https://huggingface.co/spaces/alphabell/Kernel-Trap-Cards) | Catch five hidden code bugs with browser-run candidate and reference tests. |
| [Agent Request Evidence Ladder](https://huggingface.co/spaces/alphabell/Agent-Request-Evidence-Ladder) | Separate reasoning, tool requests, reported results and intended delivery in agent traces. |
| [MOSS Layout Studio](https://huggingface.co/spaces/alphabell/MOSS-Layout-Studio) | Draw layouts and export MOSS-Image prompt JSON. |
| [MOSS Blind Layout Check](https://huggingface.co/spaces/alphabell/MOSS-Blind-Layout-Check) | Annotate one Base and SFT image pair before revealing its labels. |
| [MiniMax Video Budget](https://huggingface.co/spaces/alphabell/MiniMax-Video-Budget) | Count source-pinned vision placeholders from sampled video frames. |
| [DeepSeek Prompt Parity](https://huggingface.co/spaces/alphabell/DeepSeek-Prompt-Parity) | Explore exact prompt differences at the tool-history boundary. |
| [Flint Repair Clinic](https://huggingface.co/spaces/alphabell/Flint-Repair-Clinic) | Fix real coding failures and play the recorded repairs. |
| [Flint Request Doctor](https://huggingface.co/spaces/alphabell/Flint-Request-Doctor) | Find settings Rec MLX rejects or silently ignores. |
| [Flint Arcade](https://huggingface.co/spaces/alphabell/Flint-Arcade) | Describe a strange game, play it and remix it. |
| [Qwen Open 27B](https://huggingface.co/alphabell/alphaBell-Qwen3.8-27B-Open-FP8) | Inspect our research checkpoint, lineage and evaluation records. |
